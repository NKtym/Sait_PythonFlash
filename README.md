# Практическое занятие 1 — Flask + PostgreSQL в Render

Простое веб-приложение на Python Flask для учебной лабораторной работы.

## Возможности

- `/` — главная страница «Привет, мир!»
- `/register` — регистрация пользователя
- `/health` — проверка подключения к PostgreSQL

Регистрация сохраняется в таблицу `users`. Пароль хранится в виде хеша.

## Развертывание в Render

В проекте есть `render.yaml`. Он описывает бесплатный Web Service и бесплатную PostgreSQL и связывает их через `DATABASE_URL`.

Render: New → Blueprint → выберите репозиторий.

Free Web Service и Free Postgres подходят для учебной работы. У Free Postgres есть ограничение: база автоматически истекает через 30 дней.
